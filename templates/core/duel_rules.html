1:1 일기토 규칙

시행일: {{ effective_date }}

일기토(一騎討)는 장수 둘이 진영을 대표해 1:1로 맞붙는 결투입니다. 독존의 일기토는 보수와 진보 회원이 하나의 글을 걸고 1:1 끝장토론을 벌이고, 다른 회원들의 투표로 승패를 가립니다.

  1. 1신청상대 진영 글에서 ⚡ 버튼
  2. 2토론당사자 둘만 {{ duel_days }}일간
  3. 3투표회원 1인 1표
  4. 4판정마감 후 자동

1. 신청

  • 진보 회원은 보수 아레나의 보수 회원 글에, 보수 회원은 민주 아레나의 진보 회원 글에 ⚡ 1:1 일기토 신청을 할 수 있습니다.
  • 같은 진영의 글, 내 글, 자유 게시판 글에는 신청할 수 없습니다.
  • 한 글에는 동시에 하나의 일기토만 열립니다. 이미 진행 중이면 원본글에 "일기토 보러가기"가 표시됩니다.
  • 신청하는 즉시 일기토 게시판에 대진이 열리고 투표가 시작됩니다. 신청한 사람이 도전자, 원본글을 쓴 사람이 상대가 됩니다.
  • 운영자가 주제와 대진을 직접 정해 여는 일기토도 있습니다.

2. 끝장토론

  • 일기토 화면에는 원본글 → 투표판 → 끝장토론 순서로 보입니다.
  • 토론 글은 도전자와 원본글 작성자, 두 사람만 쓸 수 있습니다. 다른 회원은 읽고 투표로 참여합니다.
  • 토론 글 하나는 2,000자까지 쓸 수 있고, 본인 글은 삭제할 수 있습니다.
  • 일기토에는 화력(추천) 기능이 없습니다. 오직 투표로만 승부합니다.
  • 투표가 마감되면 토론 글도 더 쓸 수 없습니다.

3. 투표

  • 투표 기간은 신청 시점부터 {{ duel_days }}일입니다. 화면의 카운트다운으로 남은 시간을 확인할 수 있습니다.
  • 로그인한 회원이라면 진영과 상관없이 누구나 1인 1표를 던질 수 있습니다. 한 번 투표하면 바꿀 수 없습니다.
  • 일기토에 출전한 두 당사자는 투표할 수 없습니다.
  • 누가 어느 쪽에 투표했는지는 공개되지 않고, 득표수와 비율만 보입니다.

4. 판정과 보상

결과전적포인트
득표가 더 많으면 승리1승 추가+{{ points_duel_win }}
득표가 더 적으면 패배1패 추가+{{ points_duel_loss }} (참가 보상)
득표가 같으면 무승부반영 안 함없음
  • 마감 시각이 지나면 자동으로 판정됩니다.
  • 전적(예: 3승 1패)은 닉네임 옆에 표시되어 다른 회원에게 공개됩니다.

5. 매너와 제재

  • 일기토는 주장과 주장의 대결입니다. 상대를 조롱하거나 인신공격하는 글은 커뮤니티 가이드라인에 따라 삭제·제재됩니다.
  • 근거를 들 때는 출처를 밝혀주세요. 허위 사실로 이긴 승부는 인정받지 못합니다.
  • 여러 계정으로 투표를 조작하면 해당 일기토 결과와 포인트가 취소되고, 관련 계정은 영구 정지됩니다.
  • 원본글이 삭제되어도 일기토 기록(투표, 토론 글, 전적)은 그대로 남습니다.
  • 일기토를 신청하거나 받는 것 자체만으로 포인트를 얻을 수는 없으며, 판정이 난 뒤에 지급됩니다.
